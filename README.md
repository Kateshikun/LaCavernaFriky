
🌟 COMICS Y MANGAS

¡Bienvenido a COMCIS Y MANGAS, una página web dedicada al apasionante mundo de los cómics y mangas!
Un espacio creado por fanáticos, para fanáticos 🎨📚


---

🚀 Descripción

En COMCIS Y MANGAS podrás explorar, descubrir y disfrutar contenido sobre tus héroes, villanos y series favoritas.
El sitio está diseñado con un enfoque moderno y dinámico, utilizando tecnologías web puras y frameworks ligeros para una experiencia fluida y atractiva.


---

🛠️ Tecnologías y Frameworks utilizados

🌐 HTML5 → estructura del sitio

🎨 CSS3 → estilos y diseño responsivo

⚡ JavaScript (puro) → lógica e interactividad

🔁 AJAX → comunicación asíncrona con el servidor

💎 jQuery → manipulación del DOM y efectos dinámicos
